# Network To-do overview

- Toggle beside Logistics Network heading opens an overview in the editor; toggling off retains the previously selected location.
- Read existing planet checklists only. Completion changes update the original checklist through shared workspace persistence; no copied tasks or new collections.
- Group by system then planet, preserving order and placing prioritized planets first. Include unassigned planets under Needs a system.
- Default to pending tasks. Offer Show completed and the existing task category filters. Hide groups without matching tasks.
- Expand/collapse systems and planets. Remember filter, completed visibility, and collapse state in renderer memory for the session.
- Display each planet's completed/total count, task category, text, checkbox and linked item icons.
- Task text opens its planet with To-do selected and briefly highlights/scrolls to that task. Linked icons navigate to their item.
- Creating and reordering remain within planets. External planet navigation leaves the overview.

## Manual acceptance
1. Toggle overview and back; previous location is retained.
2. Verify pending-only default, filters, Show completed, hidden empty groups, priority sorting and counts.
3. Complete a task in overview; verify same task updates in its planet.
4. Click task text; verify planet opens with To-do selected and target highlighted. Click linked item to open item.
5. Navigate out/back; view filters and collapsed sections remain. Restart resets session preferences.
